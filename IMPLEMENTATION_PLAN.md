## 1. Architecture overview

```
 Phone (PWA)                                    Home server (later: VPS)
┌─────────────────────────────┐               ┌──────────────────────────────────────┐
│ React + Vite + TanStack     │   HTTPS       │  cloudflared (existing container)    │
│ Router                      │◀────────────▶│        │ docker network               │
│  ├─ Dexie (IndexedDB)       │  /api/sync    │        ▼                             │
│  │   own data + outbox      │  /api/feed    │  app container (Node)                │
│  ├─ TanStack Query          │  /api/events  │   ├─ Hono API  /api/*                │
│  │   social (online-only)   │   (SSE)       │   ├─ Better Auth /api/auth/*         │
│  └─ Service Worker          │               │   ├─ static SPA (built web app)      │
│      precache + push        │◀── Web Push ──│   └─ in-process jobs (push, timers)  │
└─────────────────────────────┘ (via browser  │        │                             │
                                 push service)│        ▼                             │
                                              │  postgres container (volume)         │
                                              └──────────────────────────────────────┘
```

**One app image** serves both the API and the built frontend (same origin → simple cookies, no CORS). Postgres is a second container. Cloudflare Tunnel terminates HTTPS.

## 6. Testing strategy
- `packages/shared/calc`: exhaustive table-driven unit tests (this is where subtle bugs hide).
- API: integration tests against real Postgres (CI service container): sync protocol, authorization, side effects.
- Web: repository + sync engine tests with `fake-indexeddb`; a few component tests for set-row logic.
- Playwright: (1) log a workout offline then sync, (2) template flow, (3) two users + feed (v2).
- Before marking any phase done: `pnpm typecheck && pnpm lint && pnpm test` green.

## 7. Known platform limitations (don't fight these)
- iOS push requires the PWA be installed to Home Screen (iOS 16.4+). Permission must be requested from a tap.
- No Background Sync API on Safari/Firefox → sync on open/online/visibility instead.
- JS timers pause when the app is backgrounded on mobile → always compute from timestamps.
- iOS may evict IndexedDB for sites not used in a long time; installed PWAs + `storage.persist()` mitigate. Unsynced data is the risk, so sync aggressively.
- Web Push delivery goes through Google/Apple/Mozilla push services (unavoidable, payloads are encrypted).
